# Sugar Spell delivery plan

Build an original candy match-three game for iPhone Home Screen installation.

1. Pure seeded TypeScript engine: matches, special candies, combinations, cascades, jelly, frosting, hints, boosters, and 20 levels.
2. Responsive accessible React interface: touch/keyboard play, animation, sound, local progress, level journey, tutorial, pause, and results.
3. Offline-first PWA: local assets, manifest, icons, guarded service worker updates, install instructions, and persistence recovery.
4. Validation: strict types, lint, unit invariants, Chromium/WebKit browser journeys, accessibility and offline checks, dependency audit, independent review.
5. GitHub: versioned source, least-privilege pinned Actions, checks before Pages deployment, deploy and verify the exact revision and live game.

Delivery target: GitHub Pages HTTPS URL installable through Safari Share > Add to Home Screen. Each device keeps its own progress. Native App Store/TestFlight is outside the selected Home Screen delivery route.
